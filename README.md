# MeteorClad

Top-down arena action roguelite прототип на **Lua + LÖVE2D**.

## Керування
- **WASD / Стрілки** — рух
- **ЛКМ** — удар мечем (відбиває ворожі снаряди у секторі атаки)
- **ПКМ** — Вихровий удар (360° атака та кругове відбиття снарядів)
- **Space** — ривок (Dash) із кадрами невразливості
- **1 / 2 / 3** або **ЛКМ** — вибір покращення при підвищенні рівня
- **R** — перезапуск після поразки

## Запуск
Потрібен встановлений [LÖVE2D](https://love2d.org/).
Запустіть `run.bat` або виконайте в корені проєкту:
