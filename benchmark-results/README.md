# Stage F benchmark results

Після кожного завершеного сценарію LÖVE автоматично додає рядок до:

`stage_f_benchmark_results.csv`

Файл створюється у save directory LÖVE. Точний абсолютний шлях виводиться в консолі:

`[MeteorClad Benchmark] CSV_LOG=...`

На екрані результату benchmark також натисніть **O**, щоб відкрити теку збережень LÖVE у Провіднику Windows, або **C**, щоб скопіювати повний шлях до CSV. `SAVE_DIR=...` у консолі показує каталог збережень окремо від шляху до файлу.

Після потрібної серії вимірювань скопіюйте цей CSV у цю директорію під назвою:

`benchmark-results/stage_f_benchmark_results.csv`

Потім перегляньте таблицю, за потреби заповніть колонку `manual_hardware_notes` точною моделлю CPU/GPU та закомітьте файл. Не додавайте порожній CSV або VSync-capped baseline під виглядом uncapped-вимірів.

CSV є append-only: нові прогони додаються до кінця файлу. Не видаляйте старі рядки, якщо потрібно зберегти порівняння між серіями. Для окремої чистої серії можна перейменувати або скопіювати попередній файл перед новими тестами.
