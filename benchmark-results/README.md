# Stage F benchmark і Stage G profile results

## Stage F — загальні показники кадру

LÖVE автоматично додає рядок до:

stage_f_benchmark_results.csv

Файл створюється у save directory LÖVE. Точний шлях виводиться в консолі як CSV_LOG=.... На екрані результату натисніть **O**, щоб відкрити теку, або **C**, щоб скопіювати повний шлях до Stage F CSV.

Після потрібної серії скопіюйте файл у репозиторій під назвою:

benchmark-results/stage_f_benchmark_results.csv

## Stage G — деталізація систем

Після кожного сценарію Stage G автоматично додає окремий рядок до:

stage_g_profile_results.csv

Це **окремий файл із власною схемою**, він не змінює Stage F CSV. У консолі виводиться PROFILE_CSV_LOG=... та розмір PROFILE_CSV_BYTES=.... На екрані результату натисніть **P**, щоб скопіювати точний шлях до Stage G CSV; **O** відкриває каталог збережень.

Після серії скопіюйте файл до:

benchmark-results/stage_g_profile_results.csv

Stage G зберігає average/P95/max для загального frame dt, загального update, player/enemies/projectiles/loot update, загального draw CPU submission та окремих draw-секцій.

**Інтерпретація:** вимірювання draw-секцій охоплюють CPU-час подання команд LÖVE. Вони не вимірюють фактичне виконання GPU. Профайлер додає невеликий overhead, тому Stage G — діагностична серія; не порівнюйте її FPS безпосередньо зі Stage F baseline.

## Загальні правила

CSV-файли є append-only: нові прогони додаються в кінець. Не видаляйте попередні записи, якщо потрібне порівняння. Для окремої чистої серії попередній файл можна скопіювати або перейменувати до запуску нового тесту.

Не додавайте порожній файл. Перевірте, що у ньому є рядки для завершених сценаріїв, однакові заголовки та коректний режим VSync. Після копіювання до репозиторію додайте файл окремим Git-комітом.
